# 硬體：接線、腳位、電源

腳位的唯一來源是 `firmware/car_main/config.h`；這份文件改動時要和它保持一致。

## 電源接線

全車只用一組 2S 18650 電池（7.4 V，滿電 8.4 V）：電池直接供電給 L298N 帶動馬達，再由 L298N 板上的 5 V 穩壓供電給 ESP32 和超音波。

```
18650 ×2 串聯（7.4 V）
  紅（＋）──→ 電池盒開關 ──→ L298N【12V】端子
  黑（−）─────────────────→ L298N【GND】端子

L298N【5V】 ──→ 麵包板 5V 排 ──┬─→ ESP32【VIN】
                               ├─→ HC-SR04 ×3【VCC】
                               └─→ （選配）頭燈、蜂鳴器

L298N【GND】──→ 麵包板 GND 排 ──┬─→ ESP32【GND】
                               ├─→ HC-SR04 ×3【GND】
                               └─→ 電池分壓、選配元件的 GND

470µF 電容：並在 L298N 的 12V 與 GND 之間
            長腳（＋）接 12V，有白色條紋那腳（−）接 GND
```

L298N 的 GND 螺絲孔塞不下那麼多線，所以先拉一條 5V、一條 GND 到麵包板的電源排，再從麵包板分出去。

### L298N 跳線帽設定

| 跳線帽 | 設定 | 原因 |
|---|---|---|
| 12V 跳線帽（三孔端子旁） | **保留** | 啟用板載 5 V 穩壓，5V 端子才有輸出 |
| ENA、ENB 跳線帽 | **拔掉** | 改由 ESP32 的 PWM 控制速度 |

## ESP32 腳位分配

| 元件 | 訊號 | GPIO | 說明 |
|---|---|---|---|
| L298N 左側（A 通道） | ENA／IN1／IN2 | 25／26／27 | ENA 為 PWM |
| L298N 右側（B 通道） | ENB／IN3／IN4 | 33／32／13 | ENB 為 PWM |
| HC-SR04 左前 | Trig／Echo | 16／34 | Echo 經分壓 |
| HC-SR04 正前 | Trig／Echo | 17／35 | Echo 經分壓 |
| HC-SR04 右前 | Trig／Echo | 18／36 | Echo 經分壓 |
| 電池電壓 | 類比輸入 | 39 | 20kΩ ＋ 10kΩ 分壓 |
| 頭燈（選配） | 白色 LED ×2 | 19 | 經 S8050 從 5 V 供電 |
| 煞車燈（選配） | 紅色 LED ×2 | 21 | 各串 220Ω 直接驅動 |
| 蜂鳴器（選配） | 5V 有源蜂鳴器 | 22 | 經 S8050 驅動 |

選腳原則：

- 避開 GPIO 0、2、12、15（開機模式腳）與 GPIO 6～11（接內部 Flash），否則可能開不了機。
- GPIO 34～39 只能輸入，剛好拿來接 Echo 與電池電壓。
- 電池電壓用 ADC1 的腳位（GPIO 39），藍牙運作時比較穩定。
- GPIO 16、17 在 WROOM-32 上可以自由使用；若改用 WROVER 模組，這兩支會被 PSRAM 佔用，需要換腳。

## 分壓電路

### HC-SR04 Echo（5 V → 3.3 V），三顆各一組

```
HC-SR04 Echo ──[1kΩ]──┬── ESP32 GPIO（34／35／36）
                      │
                    [2kΩ]
                      │
                     GND
```

5 V × 2k ÷ (1k + 2k) ≈ 3.3 V。Echo 直接接 ESP32 可能燒壞腳位。

### 電池電壓（8.4 V → 2.8 V）

```
電池＋（開關之後）──[20kΩ]──┬── ESP32 GPIO 39
                            │
                         [10kΩ]
                            │
                           GND
```

電池電壓 = GPIO 39 電壓 × 3。這組分壓一直會耗約 0.3 mA，所以要接在**開關之後**，關機時才不會慢慢放電。
如果還沒接這組電阻，請先把 `config.h` 的 `FEATURE_BATTERY_MONITOR` 設為 0，否則韌體會以為沒電而不讓車子動。

## 機構配置

| 位置 | 元件 | 理由 |
|---|---|---|
| 下層板 | TT 馬達 ×4、L298N、電池盒 | 壓低重心；L298N 靠近馬達，縮短大電流的線 |
| 上層板 | ESP32、麵包板、（選配）蜂鳴器 | 方便插 USB 燒錄與除錯 |
| 車側 | 電池盒開關 | 不用拆車就能開關機 |
| 車頭 | HC-SR04 ×3、（選配）頭燈 | 中間朝正前方，左右各向外偏 30°；略微朝上，避免把地板當成障礙物 |
| 車尾 | （選配）煞車燈 | |

## 第一次通電檢查

1. **先不要接 ESP32**。電池裝好、打開開關，用三用電表量：
   - 電池盒兩條線之間：7.4～8.4 V
   - L298N 的 5V 端子與 GND：約 5 V
2. 關掉開關，接上 ESP32（5V → VIN、GND → GND），再打開，確認 ESP32 的電源燈亮。
3. 用 `test_battery` 比對 ESP32 量到的電池電壓和三用電表，誤差在 0.1 V 內。這一步要同時開電池、插 USB 看序列埠，請用下一節的「USB 除錯接法」。

## 插 USB 時的兩種接法

USB 的 5 V 和 L298N 的 5 V **不可以同時接在 ESP32 上**（兩個電源互相灌電，可能燒壞 USB 埠或穩壓 IC）。依需求選一種：

| 用途 | 電池開關 | L298N 5V → ESP32 VIN 這條線 | ESP32 由誰供電 |
|---|---|---|---|
| 只燒錄、跑不需要馬達與感測器的測試（例如 `test_gamepad`） | **關** | 可以接著 | USB |
| **USB 除錯接法**：需要電池通電又要看序列埠（`test_motors`、`test_sonar`、`test_battery`、整合測試） | 開 | **拔掉**（GND 保持接著） | USB |
| 正式開車（不插 USB） | 開 | 接回去 | L298N 5V |

USB 除錯接法時：ESP32 由 USB 供電，馬達、超音波仍由電池經 L298N 供電；**GND 一定要保持共地**，否則訊號會亂掉。

切換順序（避免兩邊 5 V 碰在一起）：

- 進入除錯：關電池開關 → 拔掉 VIN 線 → 插 USB → 開電池開關。
- 回到正式開車：關電池開關 → 拔掉 USB → 接回 VIN 線 → 開電池開關。

建議 VIN 這條用杜邦線單獨拉，並貼標籤，方便插拔。

## 安全注意

- 5 V 只能接 ESP32 的 **VIN**，接到 3V3 會燒壞 ESP32。
- 所有 GND 都要接在一起，否則訊號會亂跳。
- 插 USB 時，USB 與 L298N 兩邊的 5 V 不可同時接到 ESP32：關電池開關，或拔掉 VIN 線（見「插 USB 時的兩種接法」）。
- 測試馬達前先把車架高。
- LG MJ1 是平頭電池：裝好後先量電壓，量不到電代表正極沒接觸到，可以在正極貼小塊強力磁鐵當墊片。**不要在鋰電池上焊錫。**
- 電池沒有保護板：用完一定關開關；攜帶時放收納盒，避免碰到金屬短路。
