    完整操作對照表

    操作功能測試時看什麼
    左 Joy-Con 搖桿往上／往下油門：前進／後退T 變正／變負，判讀顯示「向前／向後」
    右 Joy-Con 搖桿往右／往左轉向：右轉／左轉（坦克式：左輪 = T + S、右輪 = T − S）S 變正／變負；只推轉向時顯示「原地右轉／左轉」
    同時推油門與轉向邊走邊轉顯示「向前偏右」等，兩輪速度不同
    按住 ZR加速：速度上限 60% → 100%ZR 亮起，速度上限顯示 100%
    按「＋」切換手動／自動避障模式卡片變成「自動避障」
    A（按住）喇叭（選配）A 亮起；有接蜂鳴器且開啟 FEATURE_BUZZER 才會響
    B（按一下）車燈開關（選配）B 亮起；有接燈且開啟 FEATURE_LIGHTS 才會亮
    連上後放著不動 0.5 秒搖桿自動歸零手把狀態從「歸零中」變「就緒」，放開搖桿時 T、S 都是 0
    關掉任一支 Joy-Con斷線保護：立刻停車、回到手動1 秒內「可以開車嗎」變成「不行」、輸出歸零
    正前方 < 15 cm 時往前推防撞輔助：禁止前進、手把震動（可後退、可原地轉）判讀出現「防撞：禁止前進」

    備用 Pro 手把：左搖桿上下 = 油門、右搖桿左右 = 轉向，ZR／＋／A／B 功能相同（A/B 實際對應待測）。 只插 USB 沒接電池時，電池保護會把「實際輸出」歸零、手把會一直小震動，屬正常；看「指令」欄就知道車子本來要怎麼走。
