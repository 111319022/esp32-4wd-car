# 操作說明

> 適用 2026-11-25 之後的 `car_main`（一次只用一支手把，見 decisions.md D15；Flash LOG，見 D16）。

## 開車步驟

1. **把車架高**（第一次試新程式、或改過參數時）。
2. 打開車上的**電池開關**。USB 線不要插著；要邊開邊看序列埠，請照 `docs/hardware.md` 的「USB 除錯接法」拔掉 VIN 線。
3. 讓**一支**手把進入配對模式（見下表）。其他手把先關掉，不然可能被先連上。
4. 連上後**放著 1 秒不要碰搖桿**：程式會自動把搖桿歸零。
5. 歸零完成、搖桿在中間，就可以開車。
6. 開完**先停車，等 1～2 秒再關電池開關**：LOG 是停車後才寫進 Flash 的。

| 手把 | 進入配對模式 |
|---|---|
| Joy-Con（左或右） | 從 Switch 或握把拆下來，按住側邊滑軌上的小同步鍵，直到燈號來回跑 |
| Switch Pro 手把 | 按住頂部 USB-C 旁的小同步鍵 |
| Xbox 手把 | 按 Xbox 鍵開機，再按住頂部的配對鍵，直到 Xbox 鍵快速閃爍 |
| PS4／PS5 手把 | 同時按住 PS 鍵＋SHARE（PS5 是 PS 鍵＋建立），直到燈條快速閃爍 |

第一次配對之後，重新開機通常按手把任一鍵就會自動重連。

**一次只能用一支手把**。已經連上一支時，第二支會被拒絕，原本那支照常。要換手把：先關掉目前這支（Joy-Con 按住同步鍵約 3 秒到燈全滅），再讓新的進入配對模式。

## 按鍵

### 一支 Joy-Con（直握，一手拿）

搖桿朝上、像拿遙控器一樣直著握。

| 操作 | 右 Joy-Con | 左 Joy-Con |
|---|---|---|
| 前進／後退 | 搖桿往上／往下 | 搖桿往上／往下 |
| 左轉／右轉 | 搖桿往左／往右 | 搖桿往左／往右 |
| 加速（按住，速度上限 60% → 100%） | ZR | ZL |
| 切換手動／自動避障 | ＋ | − |
| 喇叭（選配） | A | 待實測 |
| 車燈開關（選配） | B | 待實測 |

### 大手把（Switch Pro、Xbox、PS4／PS5）

| 操作 | Switch Pro | Xbox | PS4／PS5 |
|---|---|---|---|
| 前進／後退 | 左搖桿上下 | 左搖桿上下 | 左搖桿上下 |
| 左轉／右轉 | 右搖桿左右 | 右搖桿左右 | 右搖桿左右 |
| 加速（按住） | ZR | RT | R2 |
| 切換手動／自動避障 | ＋ | ≡ 選單鍵 | OPTIONS |
| 喇叭（選配） | 下方的鍵 | A | ✕ |
| 車燈開關（選配） | 右方的鍵 | B | ○ |

只推轉向（油門放開）會**原地轉**；同時推油門和轉向是邊走邊轉。左 Joy-Con 與大手把的按鍵還沒實測，如果方向或按鍵不對，請看 `docs/software.md` 的「手把對應」修改 `config.h`。

## 車子會自己做的事

| 情況 | 車子的反應 | 手把 |
|---|---|---|
| 手動時正前方 < 15 cm 還往前推 | 不准前進（可以後退、原地轉） | 震動 |
| 左前或右前 < 10 cm | 只提醒，不干預 | 震動 |
| 自動避障模式 | 自己直行、轉彎、後退；搖桿不影響 | — |
| 手把斷線 | **立刻停車**，回到手動模式，重新開始搜尋手把 | — |
| 電池 < 7.0 V | 照常開 | 震動提醒 |
| 電池 < 6.6 V 持續 3 秒 | **停車鎖定**，要重開機才能再開 → 請充電 | 震動 |

## 事後抓錯：下載車上的 LOG

車子會把開機原因、手把連線／斷線、模式切換、防撞、自動避障的轉向與後退、電池警告，以及每秒一行狀態，存在 ESP32 的 Flash 裡，**關電也不會消失**。最多約 256 KB，約可以開車 1 小時的量，滿了會自動蓋掉最舊的。

1. 車子停下，**關掉電池開關**。
2. 用 USB 線接 ESP32 和電腦。
3. 用電腦版 **Chrome 或 Edge** 打開 `tools/gamepad_monitor.html`（Arduino IDE 的序列埠監控視窗要先關掉）。
4. 按「**連接 ESP32**」，選 ESP32 的序列埠。
5. 在「車上的 LOG」按「**下載車上 LOG**」。下載約 10～25 秒，完成後會存成 `car_flash_log_<時間>.txt`。
6. 確認看完之後，可以按「清除車上 LOG」清空（清掉就找不回來了）。

沒有網頁也可以用 Arduino IDE 的序列埠監控視窗（115200、結尾選「換行」），輸入 `log dump`（送出 LOG）、`log info`（大小）、`log clear`（清除）。

### 怎麼看 LOG

```
#12 0.418 E [log] 開機 #12，重開機原因：BROWNOUT（電壓不足：…）
#12 6.902 E [gamepad] 右 Joy-Con 已連線：…；停止搜尋其他手把
#12 9.001 S pad=1 c=JR m=MAN a=CRUISE T=312 S=0 zr=0 o=36/36 d=120/85/300 b=7.62 hz=66 lp=21
#12 12.733 E [assist] 正前 14 cm，禁止前進
```

- `#12`：第 12 次開機；`9.001`：開機後第 9.001 秒。
- `E` 是事件，`S` 是狀態快照。
- 快照欄位：`pad` 能不能開車、`c` 手把（JL 左 Joy-Con／JR 右 Joy-Con／STD 大手把）、`m` 模式、`a` 避障狀態、`T`／`S` 搖桿、`zr` 加速、`o` 左／右輪輸出 %、`d` 左前／正前／右前距離 cm、`b` 電池電壓、`hz` 手把每秒更新次數、`lp` loop 最久幾 ms。

| 你遇到的問題 | 看 LOG 的哪裡 |
|---|---|
| 車子突然自己重開機 | 下一次開機那行的「重開機原因」：BROWNOUT = 電壓不足（電池快沒電、接觸不良、馬達啟動壓降）；PANIC = 程式當機；WDT = 程式卡住 |
| 開一開突然停 | 那個時間附近有沒有 `[gamepad] … 斷線`、`[battery]`、`[assist]` |
| 手把有延遲 | 快照的 `hz`：平常大約幾十；明顯變低是藍牙問題（太遠、干擾、手把沒電）。`lp` 超過 30 代表程式卡住 |
| 自動避障撞到東西 | `[auto]` 事件的三個距離：撞到前超音波量到多少 |
| 手把連不上 | 有沒有「拒絕 …一次只能用一支手把」（有別支手把先連上了） |

最後幾秒的 LOG 是停車後才寫入的，**行駛中直接斷電**的話最後幾秒會不見；那時候要看的是下一次開機記的「重開機原因」。
