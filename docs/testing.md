### 超音波接線診斷（`tests/test_sonar_diag`）

`test_sonar` 量不到（一直是 `---`）時用這支找原因。它每觸發一顆 Trig，就同時監看三支 Echo 腳，並印出 GPIO 34／35／36／39 的實際電壓。接法和 `test_sonar` 一樣（USB 除錯接法、開電池）。

| 看到的 | 代表 |
|---|---|
| 每顆只在自己的 Echo 有數字（Trig16→Echo34、Trig17→Echo35、Trig18→Echo36），`待機=0/0/0` | 正常 |
| 某顆那一行三支都是 `---` | 那顆沒發射：VCC／GND 沒接到、Trig 沒接到，或模組壞了 |
| 某顆的數字出現在別顆的 Echo | Echo 接到別顆的腳位 |
| 自己的 Echo 顯示 `卡HIGH` | 有發射但收不到回音：前面沒東西，或模組的接收器壞了（換模組比對） |
| `待機=` 有 1 | 那支 Echo 腳被拉高或空接：分壓的 GND 沒接到、線沒插到正確的腳位 |

判斷是模組還是接線的問題：把正常的模組換到出問題的位置，問題跟著模組走就是模組壞了，留在原位就是那個位置的接線有問題。
